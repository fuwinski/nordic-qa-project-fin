
### **Документация с техническим описанием проекта для выборочного тестирования функционала веб-приложения банка.**

**В ней описаны:**
- функциональные и нефункциональные требования
- тест-кейсы и баг-репорты 
- описание работы с базой данных, включая инструкции по запуску MySQL в Docker-контейнере
- использование инструментов тестирования Postman, Charles Proxy
- автоматизация запуска коллекций Postman через Newman
- примеры Bash-скриптов
- Настройки и задачи для GitHub Actions. 

Ведение проекта осуществлялось на:
- OS Linux Ubuntu Budgie 24.10
- Браузеры Google Chrome 130.0.6723.58, Mozilla Firefox 134.0.2
